# SUCA
Is a low-cost usability evaluation platform for controlled lab settings. It records how people use a web application (clicks, mouse movement, scroll, keyboard, navigation, and DOM changes) and, in the lab, adds webcam-based eye tracking and facial signals. MIRA maps gaze to interface elements, computes task metrics such as success rate, time on task, lostness, and SUS/SEQ, and flags usability problems with supporting evidence in generated reports.

A camera-free remote mode collects interaction telemetry and questionnaires only. Video is processed on the client, and only derived signals are sent to the server. MIRA is built with a JavaScript SDK and a Django (MVC) backend, as an academic research project.
