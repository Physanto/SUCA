# SUCA

<img width="1024" height="559" alt="image" src="https://github.com/user-attachments/assets/9e0a58c2-183e-4ed7-81c4-7068f3ee68d8" />

Is a low-cost usability evaluation platform for controlled lab settings. It records how people use a web application (clicks, mouse movement, scroll, keyboard, navigation, and DOM changes) and, in the lab, adds webcam-based eye tracking and facial signals. SUCA maps gaze to interface elements, computes task metrics such as success rate, time on task, lostness, and SUS/SEQ, and flags usability problems with supporting evidence in generated reports.

A camera-free remote mode collects interaction telemetry and questionnaires only. Video is processed on the client, and only derived signals are sent to the server. SUCA is built with a JavaScript SDK and a Django (MVC) backend, as an academic research project.
